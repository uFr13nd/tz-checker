# Демонстрационные документы

Эти файлы созданы для проверки работы приложения и GitHub Actions.
Они **не являются** реальными техническими заданиями или корпоративными стандартами.

## Как проверить приложение на примерах

1. Запустите приложение: `start-local.bat`.
2. Откройте «Библиотека СТО» → «Добавить файлы СТО» → выберите
   `sto-example.md` → «Импортировать».
3. В таблице библиотеки переведите документ в статус **ACTIVE** и укажите
   редакцию, например `2026`.
4. Откройте «Проверить ТЗ» → загрузите `tz-example.md`.
5. Контекст: «ЖК, стадия ЭП, монолитный каркас, жилое здание».
6. Запустите быструю проверку.

Ожидаемые замечания:

- толщина стены 180 мм меньше требуемых 200 мм;
- предел огнестойкости REI 45 ниже требуемого REI 60;
- размер вентшахты 250 мм меньше требуемых 300 мм;
- не указана озеленённая зона 1 га в радиусе 2 км;
- коэффициенты K1/K1.1 не соответствуют СТО (0,60/0,65 вместо 0,65/0,7);
- доля машиномест для электромобилей 5 % вместо 10 %.

Часть замечаний может быть помечена как «экспертная оценка» — это нормально:
статус ACTIVE у СТО должен быть подтверждён человеком.
