Новая проверка

Сопоставление по всей библиотеке СТО: FTS + стемы + синонимы + эмбеддинги. Проверка идёт в фоне, прогресс виден на странице.

1. Проверяемое техническое задание

Файл не выбран
Закрытые ссылки не скачиваются. Для конфиденциальных документов используйте загрузку файла.

2. Дополнительные СТО (необязательно)

Файлы и ссылки добавляются в постоянную библиотеку. Для поиска по ранее импортированным СТО оставьте поля пустыми.
Файлы не выбраны
Ничего не выбрано — вся библиотека. Удерживайте Ctrl/Cmd для нескольких документов.

Настройки ИИ-провайдера

Ключ хранится локально и шифруется средствами Windows (DPAPI), если это возможно.

Провайдер

Для локальной Ollama: http://127.0.0.1:11434/v1 (не /api/chat), ключ не нужен. Для Ollama Cloud: https://ollama.com/v1 + ключ.

Семантический поиск

Если провайдер не поддерживает /embeddings, автоматически включаются локальные хэш-эмбеддинги. Настраивать ничего не нужно.
Позволяет считать эмбеддинги на локальной Ollama, если чат работает в облаке. Пусто — используется основной Base URL.

Google Sheets — сохранение реестров

Добавьте Authorized JavaScript origin, совпадающий с адресом приложения.

Токен доступа (для серверного развёртывания)

Токен хранится только в sessionStorage этой вкладки и отправляется в заголовке X-API-Token.

Журнал приложения

Файл data/tz-checker.log, ротация 2 МБ × 3. Логируются запуск и остановка, HTTP-запросы, прогоны, ошибки провайдера и предупреждения. Текст документов и ключи в журнал не попадают.

Как пользоваться

        

          
    
            
  1. В «Настройках ИИ» укажите Base URL, модель и ключ. Сохраните и проверьте подключение.
    2. 
            
  2. Импортируйте СТО в «Библиотеке СТО» и переведите проверенные документы в ACTIVE.
    3. 
            
  3. На странице проверки загрузите ТЗ, заполните контекст (или примените шаблон).
    4. 
            
  4. Посмотрите оценку числа пакетов и стоимости, выберите глубину проверки.
    5. 
            
  5. Нажмите «Проверить требования ТЗ» — анализ идёт в фоне, прогресс отображается на странице.
    6. 
            
  6. Отфильтруйте результаты по статусу, категории или тексту, изучите цитаты и рекомендации.
    7. 
            
  7. Скачайте Excel (листы «Сводка», «Результаты», «Замечания») или JSON; при необходимости сохраните в Google Sheets.
    8. 
            
  8. В истории можно сравнить два прогона и увидеть, какие замечания появились, исчезли или изменили статус.
    9. 
          

          

            Сканированные PDF без текстового слоя требуют OCR: установите Tesseract и пакеты из
            requirements-ocr.txt, затем включите TZ_CHECKER_OCR=1. Закрытые ссылки Google не обходятся.
